DHARMA DARSHAN - OFFLINE WEBSITE
=================================

1. Extract the ZIP file.
2. Open index.html in Chrome/Edge/Firefox.
3. No server, database, API or paid service is required.
4. Edit js/data.js to add/change shlok, mantras, pooja guides, festivals and calendar events.
5. The website uses Google Fonts when internet is available; all core functionality works without an API.

IMPORTANT:
The Hindu calendar included is intentionally a simple local calendar with sample/common observances. Exact tithi, sunrise, moon phase and festival dates can vary by location and traditional calculation. Verify dates before publishing as an authoritative calendar.

Files:
- index.html       Home + search
- shlok.html       Daily shlok
- mantra.html      Mantras
- pooja.html       Pooja vidhi
- festivals.html   Festival information
- calendar.html    Local editable calendar
- css/style.css    Complete responsive styling
- js/data.js       Local content data
- js/app.js        Website functionality
